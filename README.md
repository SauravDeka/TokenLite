# TokenLite

### Intelligent Document Optimization for Large Language Models

TokenLite is a Python-based document optimization application built with Streamlit. It converts documents into clean, AI-friendly text, analyzes token usage, and safely removes repetitive document-level artifacts while preserving meaningful content.

The goal of TokenLite is to make documents more suitable for processing by Large Language Models (LLMs) without summarizing, paraphrasing, or removing important information.

---

## 🚀 Features

- 📄 Upload and process supported documents
- 🔄 Convert documents into clean, usable text
- 📊 Analyze characters, words, lines, and tokens
- 🧹 Detect repetitive document-level artifacts
- ✂️ Remove repeated page headers and footers
- 🔢 Remove unnecessary page markers
- 🛡️ Preserve meaningful document content
- 📋 Compare converted and optimized outputs
- 💾 Download both converted and optimized outputs
- ✅ Verify that meaningful content is preserved
- ⚡ Reduce unnecessary token usage through safe document cleanup
